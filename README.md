# Noodle Node 🍜

Noodle Node is a mobile-first visual thinking web app for organizing, connecting, comparing, and shaping ideas.

## Current prototype

This repository contains the first interactive prototype based on the product/design specification developed in ChatGPT.

Implemented in this first version:
- Night Chinatown × starry sky × neon visual identity
- Mobile-first home with recent maps, folders, favorites and search
- Mind-map canvas with draggable nodes and connectors
- Mind / free / list / flow view switching
- Node detail bottom sheet with memo, tags, importance and task fields
- Task view
- Comparison / decision view with weighted scoring
- Final summary view with text export and print/PDF
- Theme / typography / start-screen settings
- Local autosave using `localStorage`

## Run locally

No build step is required. Open `index.html` in a browser or serve the repository with any static web server.

## Next implementation phases

The full product specification also includes Google sign-in, cloud sync, real-time collaboration, sharing permissions/links, version history, backups, template sharing, richer import/export, and cross-device persistence.

## Design language

- Deep navy base
- Neon red for important actions
- Warm gold for decisions / confirmation
- Translucent glass cards
- Rounded rectangular nodes
- Home: stronger Chinatown atmosphere
- Editor: quieter star-field canvas
